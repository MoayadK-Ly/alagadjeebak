# 💸 على قد جيبك (Alagadjeebak)
> لعبة تحديات وميزانية ذكية وحفلات جماعية بالريال السعودي مع تحكيم الذكاء الاصطناعي 🇸🇦

---

## 🌟 المميزات والمواصفات المعتمدة:

1. **الهوية والبوابة الصارمة (Identity Gatekeeper):**
   - الاسم إلزامي لإنشاء أو الانضمام لأي غرفة.
   - اختيار الأيقونة (Emoji) من كيبورد الجوال مع نظام تحقق صارم يرفض الأحرف والأرقام.
   - وسم دائم ومميز (مثل `#KSA-841`) وسجل انتصارات دائم محفوظ في `localStorage`.

2. **نظام الغرف السحابية (2 إلى 8 لاعبين):**
   - كود سري مؤقت صالح لمدة **10 دقائق** مع عداد تنازلي نشط: `⏳ صلاحية الكود: 09:59`.
   - إمكانية التجديد اليدوي بضغطة زر أو التجديد التلقائي عند الصفر.
   - دعم كامل للعب الجماعي السحابي (Real-time Cloud Multiplayer عبر WebSockets).

3. **الميزانية والجولات الديناميكية:**
   - 25 ريال 👈 6 جولات (الوضع الخاطف).
   - 50 ريال 👈 8 جولات (الوضع المتوازن).
   - 100 ريال 👈 10 جولات (الوضع التكتيكي).
   - 200 ريال 👈 14 جولة (وضع الهوامير).
   - توقيت الجولة: **20 ثانية** مع الانتقال التلقائي الفوري بمجرد اتخاذ الجميع للقرار.

4. **المواضيع الستة ورسومات SVG الحية (Interactive Vector Graphics):**
   - 🏎️ سيارة رياضية خارقة (أبواب لمبو، جنوط سبور، نيترو، كفرات Monster، نيون RGB).
   - 🏡 فيلا وقصر الأحلام (مسبح أولمبي، حديقة نخيل، مهبط هليكوبتر، روف لاونج).
   - ☕ مقهى وكافيه عصري (ماكينة إسبريسو مذهبة، لوحة نيون، ترّاس خارجي، محمصة).
   - 🍔 مطعم فاخر (طاولات رخام، مطبخ مفتوح وشواء، عازف بيانو، ثريات).
   - 🏢 برج وناطحة سحاب (مطعم دوار 360°، مهبط تاكسي طائر EVTOL، عروض ليزر).
   - ✈️ طائرة خاصة فاخرة (أجنحة ذهبية، محركات نفاثة بتوهج حراري، جناح نوم).

5. **الميكانيكا التنافسية:**
   - **الستارة السرية المشفرة (Secret Curtain):** حجب تفاصيل مشتريات المنافسين من السيرفر.
   - **معاينة خاطفة 👁️:** إمكانية اختلاس نظرة لمدة ثانية واحدة فقط على مشروع الخصم.
   - **كروت المقالب 😈:** ساهر 📸، سطحة وتشليح 🧰، عين حسود 🧿، شريطي المعارض 🤝.
   - **جولة المزاد السري « حراج 🔨 »:** مزايدة سرية على قطع استثمارية نادرة.
   - **الأحداث الطارئة 🌪️:** موجة غبار، تفتيش بلدي، كاش باك، ترند سناب.
   - **التفاعلات الحية 💬:** فقاعات تعبيرية تطفو بلحظتها (💸 طفرنا!، 😱 يا ساتر!، 🤣 ضحك!).

6. **حفل التتويج والـ AI:**
   - كشف جماعي لكل الستائر بالتزامن.
   - منصة تتويج ثلاثية (🥇 ذهبية، 🥈 فضية، 🥉 برونزية).
   - نسب مئوية دقيقة مجموعها 100%.
   - تقرير وتحليل ذكي وساخر من حكم الذكاء الاصطناعي.

## 🚀 طريقة التشغيل السريع:

### التشغيل المحلي:
```bash
npm install
npm start
```
ثم افتح الرابط: `http://localhost:3000`

### النشر السحابي المجاني (Render / Docker / Railway):
- المشروع مجهّز بملفات:
  - `render.yaml`
  - `Dockerfile`
  - `Procfile`
- يمكنك رفعه إلى مستودع GitHub وربطه بـ Render ليصبح متاحاً للعالم في دقيقة واحدة!
